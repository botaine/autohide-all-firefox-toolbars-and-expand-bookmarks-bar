what it does:
after install, your tab bar, address bar and bookmarks bar of firefox will hide automatically when you move the mouse away from the toolbar area after a 400 millisecond delay. they will all reappear when you move the mouse back to the top of the firefox window. the bookmarks bar will also show a maximum of 10 rows at a time so it is more useable. scroll up and down if you reach 10 rows of bookmarks with the mousewheel or the scrollbar on the right. folders within the bookmarks bar expand inline with the bookmarks already there instead of the default behavior. opened folders appear with an outline. when you download a file, all the toolbars and the download popup display for 4 seconds. since you don't need fullscreen mode when you use this mod, instead of the normal useage, turning fullscreen mode on will make all the toolbars stay open so you can see them all at once along with the whole web page, to give the appearance of temporarily switching off the mod if needed. everything works the same maximized and when in a smaller window. this mod works as a replacement for fullscreen mode. you don't have to click fullscreen anymore to hide the toolbars. see the demonstration video here https://www.youtube.com/watch?v=jRXupDJYr14

pre-requisite:
Firefox browser installed in Windows 11

installation using installer:
Click here to download https://github.com/botaine/autohide-all-firefox-toolbars-and-expand-bookmarks-bar/releases/download/release/autohide-all-firefox-toolbars-and-expand-bookmarks-bar.zip in releases. extract it, open it then run install.bat . Follow the prompts in the installer. The installer works well when I test it but if it doesn't work for some reason, install manually as described below. running the install.bat file will install the full version, including fx-autoconfig. running the uninstall.bat file will remove everything including fx-autoconfig. in about:config, toolkit.legacyUserProfileCustomizations.stylesheets will also be changed as needed. if you already have a customized userChrome.css file, move it somewhere else or rename it when installing because it may get overwritten.

manual installation:
in firefox, open about:config by typing it into the address bar, then seach for toolkit.legacyUserProfileCustomizations.stylesheets . set it to true. this allows firefox to use the userChrome.css file. then go to the releases page here https://github.com/botaine/autohide-all-firefox-toolbars-and-expand-bookmarks-bar/releases/tag/release and download autohide-all-firefox-toolbars-and-expand-bookmarks-bar.zip. extract the downloaded zip file by right clicking on it, then click extract all, then extract. this creates a new extracted version of the folder. open it.  put userChrome.css in the chrome folder of your firefox profile. to find that location, in the address bar of firefox type in about:profiles and press enter. then find root directory of the profile in use and click open folder there. the windows explorer location of the firefox profile opens. in that folder create a new folder named chrome if it doesn't exist already, then open it. if it does exist already just open it. put the downloaded userChrome.css file into that chrome folder. if you already have something in an existing userChrome.css file there, you may not want to overwrite it. instead you should be able to copy the code from the recently downloaded userChrome.css file then paste it to the bottom of the code in your original userChrome.css file, then save it.

install fx-autoconfig from here so that firefox can use javascripts on the browser UI https://github.com/MrOtherGuy/fx-autoconfig . be sure to complete both the "Setting up config.js from program folder" and the "setting up profile" portion of the install. put all of the downloaded .js files of autohide-all-firefox-toolbars-and-expand-bookmarks-bar into the <firefox_profile>/chrome/JS folder. <firefox_profile> is not the actual name of the folder, it represents the seemingly random letters and numbers that your firefox profile folder name happens to be. restart firefox if opened already, or open it if it was closed. right click in your tab bar, go to bookmarks toolbar, then click "always show". your bookmarks bar will be shown now on multiple rows. you can change this setting back to "never show" to hide the bookmarks if you prefer. the Claude AI can help with install difficulty at any stage.
