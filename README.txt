what it does:
after install, your tab bar, address bar and bookmarks bar of firefox will hide automatically when you move the mouse away from the toolbar area after a 400 millisecond delay. they will all reappear when you move the mouse back to the top of the firefox window. the bookmarks bar will also show a maximum of 10 rows at a time so it is more useable. scroll up and down if you reach 10 rows of bookmarks with the mousewheel or the scrollbar on the right. folders within the bookmarks bar expand inline with the bookmarks already there instead of the default behavior. everything works the same maximized and when in a smaller window. this works somewhat as a replacement for fullscreen mode. you don't have to click fullscreen anymore to hide the toolbars. see the demonstration video here https://www.youtube.com/watch?v=jRXupDJYr14

pre-requisite:
Firefox browser installed in Windows 11

installation:
Extract the downloaded autohide-all-firefox-toolbars-and-expand-bookmarks-bar.zip in releases, open it and run install.bat . Follow the prompts in the installer. If that doesn't work for some reason, install manually as described below. I need to change a few things with the installer but it should work. I recommend doing a "test install" for now because it lets you specify where your firefox install location and profile are.

in firefox, open about:config by typing it into the address bar, then seach for toolkit.legacyUserProfileCustomizations.stylesheets . set it to true. this allows firefox to use the userChrome.css file. then go to the releases page here https://github.com/botaine/autohide-all-firefox-toolbars-and-expand-bookmarks-bar/releases/tag/release and download autohide-all-firefox-toolbars-and-expand-bookmarks-bar.zip. extract the downloaded zip file by right clicking on it, then click extract all, then extract. this creates a new extracted version of the folder. open it.  put userChrome.css in the chrome folder of your firefox profile. to find that location, in the address bar of firefox type in about:profiles and press enter. then find root directory of the profile in use and click open folder there. the windows explorer location of the firefox profile opens. in that folder create a new folder named chrome if it doesn't exist already, then open it. if it does exist already just open it. put the downloaded userChrome.css file into that chrome folder. if you already have something in an existing userChrome.css file there, you may not want to overwrite it. instead you should be able to copy the code from the recently downloaded userChrome.css file then paste it to the bottom of the code in your original userChrome.css file, then save it. restart firefox if opened already, or open it if it was closed. right click in your tab bar, go to bookmarks toolbar, then click "always show". your bookmarks bar will be shown now on multiple rows. you can change this setting back to "never show" to hide the bookmarks if you prefer. the Claude AI can help with install difficulty at any stage. All of the below optional installs are recommended for the best experience in my opinion but you may have different preferences. Read through them and decide which you want at this point in the install. 

if you aren't sure what you want after reading below it is probably best to do the full install, then you can test each .js file to see if you like it being added by simply renaming the file to something other than the original file name and then it won't be used. change the .js file you are testing back to the original name and it will work again. it is easiest to just add a few characters to the file name to make it not be used, then delete the extra characters to go back to the original file name and use the file. restart firefox to see the changes take effect.

For the full install:
install fx-autoconfig from here so that firefox can use javascripts on the browser UI https://github.com/MrOtherGuy/fx-autoconfig . be sure to complete both the "Setting up config.js from program folder" and the "setting up profile" portion of the install. then download all of the .js files and put them in the <firefox_profile>/chrome/JS folder. <firefox_profile> is not the actual name of the folder, it represents the seemingly random letters and numbers that your firefox profile folder name happens to be.

optional install to get cross window tab dragging working better:
if not installed already, install fx-autoconfig from here so that firefox can use javascripts on the browser UI https://github.com/MrOtherGuy/fx-autoconfig . be sure to complete both the "Setting up config.js from program folder" and the "setting up profile" portion of the install. then download the cross-window-drag.uc.js file and put it in the <firefox_profile>/chrome/JS folder. <firefox_profile> is not the actual name of the folder, it represents the seemingly random letters and numbers that your firefox profile folder name happens to be. this optional install will make every firefox toolbar in all windows go into the unhidden state while you are moving a firefox tab. if you don't want to do this part but still want to move tabs around easier you can do a workaround of changing the hide delay in userChrome.css to something like 3000ms. look for this to change near the top of the file --uc-autohide-toolbar-delay: 0400ms;

optional install to make folders on the bookmarks bar open inline with other bookmarks on the bookmarks bar:
if not installed already, install fx-autoconfig from here so that firefox can use javascripts on the browser UI https://github.com/MrOtherGuy/fx-autoconfig . be sure to complete both the "Setting up config.js from program folder" and the "setting up profile" portion of the install. then download the inline-bookmark-folders.uc.js file and put it in the <firefox_profile>/chrome/JS folder. <firefox_profile> is not the actual name of the folder, it represents the seemingly random letters and numbers that your firefox profile folder name happens to be. if you don't use folders on the bookmarks bar or you just prefer the original look, then this file isn't necessary.

optional install to make toolbars appear for 4 seconds when a download starts and finishes:
if not installed already, install fx-autoconfig from here so that firefox can use javascripts on the browser UI https://github.com/MrOtherGuy/fx-autoconfig . be sure to complete both the "Setting up config.js from program folder" and the "setting up profile" portion of the install. then download the download-forceopen.uc.js file and put it in the <firefox_profile>/chrome/JS folder. <firefox_profile> is not the actual name of the folder, it represents the seemingly random letters and numbers that your firefox profile folder name happens to be. I added this because I didn't like not being able to tell when a download starts and finishes because the toolbars were hidden. if you want the toolbar to appear for a different amount of time you can change all the 4000 values (representing 4000 milliseconds) to any number you want in milliseconds.
